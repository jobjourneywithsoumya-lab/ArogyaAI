## 🚀 Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn
- <!-- TODO: any required API keys or services -->

### Installation

```bash
# Clone the repository
git clone https://github.com/soumyanh07/ArogyaAI.git
cd ArogyaAI

# Install dependencies
npm install

# Set up environment variables
cp .env.example .env
# Fill in the required values in .env
```

### Running Locally

```bash
npm run dev
```

The app will be available at `http://localhost:5173` (default Vite port).

### Build for Production

```bash
npm run build
```
